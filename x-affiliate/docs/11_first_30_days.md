# 最初の30日間の行動計画

「あなた」の作業は太字。それ以外は自動、または Claude が実施。

## Day 0〜3：セットアップ

- **リポジトリ作成・ドメイン購入・Cloudflare Pages 接続（チェックリスト1〜3）**
- Claude：リポジトリ移行、`config/site.yaml` / `brand.yaml` のドメイン・ハンドル・解析トークンを反映
- サイト公開（記事7本＋運営方針＋プライバシーポリシー）→ ASP審査に出せる状態
- **Xアカウント作成・プロフィール設定・固定ポスト（チェックリスト4）**
- **X API・Anthropic APIキー取得、Secrets 登録（チェックリスト5〜7）**
- **ASP登録・提携申請（チェックリスト8）** ※ 審査は数日〜2週間。提携前でもサイトとXは問題なく動きます

## Day 4〜7：自動運用の開始

- 「XA: weekly content PR」を手動実行（Actions → Run workflow）するか、土曜の定期実行を待つ
  - 厚労省データの初回取得 → `/data/` 業種・企業ページが公開される
  - 30日プランの1〜7日目が翌週の日付で PR に入る
- **PRを読んでマージ（初回は30分ほど、全体の雰囲気を確認）**
- 翌週月曜 07:45 から自動投稿開始

## Week 2：信頼の土台づくり（Day 8〜14）

- 自動：会社を見分ける7項目・面接の質問・本の投稿、A/Bテスト1（フック比較）
- 自動：記事1本生成（バックログ先頭「業種別の傾向」）→ PR
- **PRマージ（15分）**
- **提携が承認されたら、リンクURLを Claude に渡す or `links.yaml` に貼る（10分）** → 記事・データページのCTAが自動で有効化、PR表記も自動挿入

## Week 3：データ公開と送客開始（Day 15〜21）

- 自動：DB集計の中央値投稿（実データで置換）、賃金差異の読み方記事へ送客、A/Bテスト2
- 自動：週次レポートに初めての実績（インプ・ER・クリック）が載る
- **PRマージ（15分）**

## Week 4：業種別データと成約導線（Day 22〜30）

- 自動：業種別の上位/下位、エージェント選び・コーチング記事への送客
- 自動：プランを使い切る週から、Claude が学習メモをもとに投稿を生成
- **PRマージ（15分）**
- **月末：ASP管理画面を見て `kpi_monthly.csv` に1行（5分）**

## 30日時点の目標（判断基準）

| 指標 | 目標 | 未達時の自動対応 |
|---|---|---|
| 投稿 | 60本（missed 0） | missed が出たらマージ曜日を前倒し |
| フォロワー | 150〜500人 | A/Bの勝ちフックを翌月の型に固定 |
| 月間インプ | 3万〜10万 | A比率を+5%（`config/schedule.yaml`） |
| サイト訪問 | 300〜1,000 | E投稿の「記事で分かること」を具体化 |
| ASP提携 | 主要案件3つ以上 | 否認案件は同カテゴリの別案件に申請 |
| 記事 | 11本（初期7＋週1×4） | — |
| オーナー作業 | 初期設定後 合計1.5時間以内 | 超えたら Claude に作業の自動化を依頼 |

報酬は30日ではほぼ発生しない想定です（ASP承認・検索流入の立ち上がり待ち）。**3か月目で月1万円**が最初のマイルストーンです。
