
- ヘッダー：ミモザ色（#F2C230）の背景に「女性の働き方を、数字で選ぶ。」の一文のみ

```

すべて出典つきです。サイトはこちら👇
（リプ欄にURL）
```

## ポジショニング

|  | 体験談・共感 | データ・制度 |
|---|---|---|
| **主張・論争** | 個人のフェミニスト発信者（炎上・疲弊リスク） | 研究者・記者（専門的で硬い） |
| **実用・選択** | キャリア系インフルエンサー（自己啓発、転職推し） | **ミモザデータ（ここ）**：やさしい言葉で、数字を「自分の選択」に使えるようにする |

## キャラクター設定

- **ミモザ編集部**：公開データを読み解く「データ担当」の編集部。AIと一緒に調べ、人間が最終確認する
- 一人称は「編集部」。**個人の顔・年齢・経歴を設定しない**（実在しない人物の体験を語らないため）
- 価値観：女性が不利になりやすい構造を、努力論ではなく数字と制度で見る／誰も敵にしない／選択肢を増やす
- 口癖的な型：「数字の意味 → それが示すこと → あなたにできること」

## 文体

- です・ます調。落ち着いて、少し温かい。上から目線にしない
- 1投稿1メッセージ。改行多め、箇条書きは「・」
- 断定は出典のある事実だけ。解釈は「〜と読めます」「〜かもしれません」
- 絵文字0〜1個。ハッシュタグは原則なし（#PRのみ）

## 発信テーマ（5本）

1. **男女の賃金差異を読み解く**（定義・業種差・読み方の注意）
2. **働きやすい会社の見分け方**（公開データ・認定・口コミ・面接での確認）
3. **転職・異動・交渉の選択肢**（転職だけを勧めない）
4. **制度・法改正をやさしく**（育休、女性活躍推進法、柔軟な働き方の措置）
5. **働き方とジェンダーを考える本**（週末枠）

## フォローする理由（読者にとって）

- 自分の業界・会社の「数字」が分かる
- 転職・就活で使える具体的なチェック方法と質問が手に入る
- 出典つきで、怒りや不安を煽られない（安心して読める）

## 競合との差別化

| 競合 | 彼らの強み | ミモザデータの差別化 |
|---|---|---|
| キャリア系インフルエンサー | 共感・体験談 | 体験談の代わりに**検証可能なデータ** |
| 転職メディア | 求人数・SEO | 求人ではなく**企業の公表データ**という中立の物差し |
| 口コミサイト | 生の声 | 口コミと対になる**公式の数字**（併用を提案＝送客先にもなる） |
| フェミニスト論客 | 主張の強さ | 主張ではなく**選択に使える情報**。対立を作らない |

## NG事項（`config/brand.yaml` で機械的にもチェック）

- 男性叩き・女性叩き、主語の大きい一般化（「男は」「女は」等）
- 体験談の捏造（「私が転職したとき」「友達が」等）、実在しない人物のなりすまし
- 怒りを誘う引用RT、晒し、皮肉、論争への参戦
- 企業への断定的な評価（「ブラック」「ひどい」）、ランキングでの貶め
- 出典のない数字、「絶対」「必ず」「No.1」「稼げる」「年収が上がる」
- PR表記のない広告、Amazonリンクを使った有料広告
- 自動リプライ・自動いいね・自動フォロー・他人への自動メンション（X自動化ルール）
- 返信・DMでの個別キャリア相談（専門家ではない・作業時間が増える）→ 固定の案内文で記事へ
