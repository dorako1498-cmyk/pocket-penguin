# コンプライアンス・運用ルール

## 1. 広告表示（景品表示法・ステマ規制）

- アフィリエイトリンクを含む記事・ページ：冒頭に【PR】表記（`build_site.py` が有効なアフィリンクを検知して自動挿入）
- 広告を含む記事へ誘導する X 投稿：本文に `#PR`（`affiliate: true` の投稿は lint が `#PR` を強制）
- サイト共通フッター・プライバシーポリシーに、アフィリエイト参加と評価基準の独立性を明記
- Amazonアソシエイト参加時は定型の表示文（`templates/privacy.html` に用意済み）

## 2. 表現（景表法・誇大表現）

- 禁止語は `config/brand.yaml` の `ng`（正規表現）で一元管理。投稿生成時・投稿直前・CIでチェック
- 順位づけをする場合は、基準を本文に明記。「おすすめNo.1」等の根拠のない表現は使わない
- 「稼げる」「年収が上がる」など、成果を約束する表現は使わない

## 3. 事実と出典

- 数値・制度・法律に触れる投稿は `sources` 必須（lint で強制）
- データ由来の数値は `{{stat:...}}` のみ。未取得なら投稿・表示しない
- 統計は一次資料（官公庁・企業公表）を出典にする。ニュースは見出しをネタにするだけで本文は転載しない
- 厚労省オープンデータの出典表記：「厚生労働省『女性の活躍推進企業データベース』オープンデータ（取得日）を加工して作成」

## 4. 企業データの扱い（名誉・信用）

- 公表値をそのまま掲載し、評価語（ブラック・ひどい・最悪 等）を使わない
- 「ランキング」ではなく「公表値の並べ替え」と明記
- 値は企業の自己公表であり、算定範囲・時点が異なることを各ページに表示
- 訂正依頼の窓口（`/about/#corrections`）を設置し、連絡があれば確認して修正

## 5. ペルソナの誠実さ

- 一人称は「編集部」。個人の顔・年齢・経歴を作らない
- 実在しない人物の体験談を事実のように語らない（lint の `fake_experience` で検知）
- AIを使っていることをプロフィール・運営方針・記事末尾で開示

## 6. X のルール

- 公式 API のみ使用。自分のオリジナル投稿の予約投稿だけを自動化
- 自動リプライ・自動いいね・自動フォロー・自動DM・他人への自動メンションはしない
- 同一内容の連投をしない（F 再利用は切り口を変えて30日以上空ける）
- 1回の実行で最大2投稿、予定から6時間超過分は投稿しない

## 7. 扱わない領域

- 金融商品（投資勧誘・断定的判断の提供のリスク）
- 美容・健康・医療（薬機法・医療広告ガイドライン）
- 退職代行・法律相談の紹介（弁護士法）
- 求人の直接紹介（職業安定法上の職業紹介に当たる行為はしない。許可事業者へのリンクのみ）
- 有料広告によるアフィリエイトリンクの配信（Amazon規約で報酬対象外、他ASPでも制限が多い）
